# Parallel Search System

Coursework: Parallel Computing

## Project Description
A parallel search engine with an inverted index
and integration with a local Ollama LLM.

## Technologies
- Java
- Multithreading
- REST API
- WebSocket
- Ollama
- Docker Compose

## Features
- Parallel inverted index construction
- Configurable thread pool
- Concurrent document search
- LLM-based query expansion
- Web UI and CLI clients
