# Демонстраційний датасет

Один `.txt` файл у UTF-8 — один документ. Завантажувач рекурсивно обходить каталог, сортує шляхи, ігнорує символічні посилання та файли без суфікса `.txt`. ID — відносний шлях із `/`; `path` документа — абсолютний нормалізований шлях.

Порожній каталог і порожні файли дозволені. Відсутній каталог, помилка читання або некоректний UTF-8 спричиняють IOException, а не мовчазне пропускання документа.

`sample/` містить чотири невеликі авторські документи українською й англійською про обчислення та пошук. Слово `пошук` є в `04-llm.txt`, а `java` двічі в `03-java.txt`, але posting для цього документа буде один. Морфологічне приведення слів не виконується.
